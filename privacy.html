2. Какие данные обрабатываются

При заполнении формы записи пользователь может предоставить имя, номер телефона, выбранную услугу, размер колёс, желаемую дату и время записи, комментарий. При работе сайта технически могут обрабатываться сетевые данные, необходимые для передачи запроса.

3. Цели обработки

Данные используются для приёма заявки, проверки доступного времени, связи с клиентом, подтверждения и организации оказания услуги, а также обработки запросов, связанных с записью.

4. Основания обработки

Основанием обработки данных, предоставленных через форму, является согласие пользователя, выраженное установкой отметки в форме, а также иные применимые законные основания в случаях, предусмотренных законодательством.

5. Действия с данными и хранение

Оператор может осуществлять сбор, запись, систематизацию, накопление, хранение, уточнение, использование, передачу уполномоченным обработчикам, блокирование и удаление данных в объёме, необходимом для указанных целей. Доступ предоставляется только лицам, которым он необходим для работы с заявками. Данные хранятся до достижения целей обработки либо до отзыва согласия, если отсутствуют иные законные основания для продолжения обработки. Если законодательство требует более длительного хранения отдельных сведений, применяются установленные законом сроки. После прекращения законных оснований данные удаляются или обезличиваются в предусмотренном законом порядке.

6. Используемые сервисы

Сайт размещается с использованием GitHub Pages, а заявки обрабатываются с использованием Supabase. Обработка с привлечением этих сервисов осуществляется в пределах применимых законных оснований. Сведения о расположении серверов и возможной трансграничной передаче данных должны соответствовать фактическим настройкам используемых сервисов.

7. Защита данных

Оператор принимает необходимые организационные и технические меры для защиты персональных данных от неправомерного доступа, изменения, раскрытия и уничтожения. Конкретные меры и настройки доступа должны соответствовать фактической конфигурации сайта и базы данных.

8. Права пользователя

Пользователь вправе запрашивать сведения об обработке своих данных, требовать их уточнения, блокирования или удаления в предусмотренных законом случаях, а также отозвать согласие. Для обращения используйте контакт оператора, указанный в разделе 1. Отзыв согласия не всегда исключает обработку, допускаемую по другим законным основаниям.

9. Изменения политики

Оператор может обновлять политику. Актуальная версия публикуется на этой странице.
